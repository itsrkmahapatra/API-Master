# API Master 🚀

**API Master** is a premium, static, open-source API testing tool designed for modern developers. It provides a clean, professional, and high-performance interface to test REST, GraphQL, and WebSocket APIs directly from your browser.

Created by **[Raj Kishor Mahapatra](https://github.com/itsrkmahapatra)**.

## 💡 Why API Master?

Many API testing tools are bulky, require installation, or harvest your data. **API Master** is different:
- **Zero Install**: Runs entirely in your browser.
- **Privacy First**: Your requests and history stay in your browser's local storage.
- **Developer-Centric**: Designed with a theme that feels like home for GitHub users.
- **Lightweight**: Pure Vanilla JS, no bloat.

## ✨ Features

- **REST Client**: Support for GET, POST, PUT, DELETE, and PATCH with dynamic headers and JSON body validation.
- **GraphQL Client**: Dedicated interface for queries, mutations, and variables.
- **WebSocket Client**: Real-time connection management with status indicators and message logs.
- **History Manager**: Persists the last 20 requests in `localStorage` for easy access.
- **Response Viewer**: Built-in JSON syntax highlighting, response timing, and status badges.
- **Import/Export**: Save and load your request collections as JSON files.
- **GitHub Theme**: Professional Dark/Light mode toggle inspired by GitHub's aesthetic.
- **No Backend Required**: 100% static SPA. Your data never leaves your browser.

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/itsrkmahapatra/api-master.git
   ```
2. **Open `index.html`**: Simply open the file in any modern web browser.
3. **Start Testing**: Choose your protocol (REST/GraphQL/WS) and send your first request!

## 🛠️ Built With

- **HTML5 & CSS3**: Custom CSS variables for theme management.
- **Vanilla JavaScript**: Pure ES6+ logic for state and networking.
- **SVG**: Geometric branding and icons.

## 📖 How to Test

- **REST**: Enter a URL like `https://jsonplaceholder.typicode.com/posts/1` and click **Send**.
- **GraphQL**: Enter an endpoint like `https://countries.trevorblades.com/` and run a query.
- **WebSocket**: Connect to `wss://echo.websocket.org` to test real-time messaging.
