# Contributing to API Master 🤝

First off, thank you for considering contributing to **API Master**! It's people like you who make it a great tool for the developer community.

## 🌈 How Can I Contribute?

### Reporting Bugs 🐛
- Use the **Bug Report** template.
- Describe the steps to reproduce the issue.
- Include information about your browser and environment.

### Suggesting Enhancements ✨
- Use the **Feature Request** template.
- Explain why this enhancement would be useful.

### Pull Requests 🛠️
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the UI remains consistent with the **GitHub-friendly** theme.
4. Open a Pull Request with a clear description of your changes.

## 🎨 Coding Standards
- Keep it **Vanilla JS** and **CSS**. No heavy frameworks please!
- Use semantic HTML.
- Follow the existing indentation and naming conventions.

## 📜 Code of Conduct
Please be respectful and professional in all your interactions with the community.
